# 变更记录

## 0.0.3

- **多楼层地图**：按 SVG 图层拆出各楼层，工具栏可切换
  - 海关 5 层（地面 / 1 / 2 / 3 / 地下）、立交桥 3 层（地面 / 1 / 2）、工厂 4 层、
    海岸线 5 层、街区 7 层、零号地 5 层、终点站 2 层
  - 楼上图层会把地面层压暗作为底图，保留方位感
  - 标记带楼层：在几层打的点就画在几层，不会楼上楼下混在一起
  - 队友的点在所有楼层都显示（用的是同一套世界坐标），坐标板里可以看高度
  - 储备站上游只有地面与掩体两个图层，建筑内部楼层没有独立矢量图层，暂时无法拆
- 渲染脚本支持按图层渲染（内联 SVG → 隐藏其他楼层 → 序列化回图片）

## 0.0.2

- **地图朝向修正**：所有地图统一转为北朝上（此前渲染出来是南北颠倒的）
- 隐藏 Windows/Linux 上的默认菜单栏（File/Edit/View…），界面更干净
- 应用图标：新增自绘的矢量图标（深色圆角 + 定位针 + 坐标准星），
  由 `tools/build-icon.mjs` 生成 `build/icon.png` 与 `build/icon.ico`
- 首次打包分发：Windows 安装包 + 免安装 zip，macOS zip
